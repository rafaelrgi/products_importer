# Products Importer System

A robust, enterprise-grade full-stack solution designed for high-performance data ingestion and visualization. This monorepo integrates a distributed architecture using **.NET**, **Angular**, and **Flutter**.

<br>

## 🛠 Project Architecture

The system is built on a **Clean Architecture** foundation, ensuring separation of concerns and scalability. It handles the complete lifecycle of product data: from bulk file ingestion to cross-platform visualization.

<br>

## 📁 Repository Structure

* **`/backend`**: ASP.NET Core Web API following Clean Archtechture and good code principles like SOLID.
* **`/frontend`**: Angular enterprise dashboard for data visualizations and management.
* **`/mobile`**: Flutter application for on-the-go upload  and tracking data.

<br>

## 🚀 Getting Started

1. **Prerequisites:** Docker, .NET 9 SDK, Node.js, and Flutter SDK.
2. **Clone the repo:** `git clone git@github.com:rafaelrgi/products_importer.git`
3. **Run the projects:** you can find detailed instructions:
    - [Backend](./backend/README.md)
    - [Mobile](./mobile/README.md)
    - [Frontend](./frontend/README.md)
